# Alpha-Tech Repair Documentation

ศูนย์กลางเอกสารสำหรับโมดูลรับซ่อมและการส่งมอบอุปกรณ์ของ Alpha-Tech

## ลำดับเอกสารที่รับรอง

1. [คู่มือการดำเนินงานรับซ่อม](./01-business-operation-manual.md)
2. คู่มือผู้ใช้งาน — อยู่ในลำดับถัดไป
3. คู่มือผู้ดูแลระบบ — อยู่ในลำดับถัดไป
4. เอกสารอ้างอิงทางเทคนิค — อยู่ในลำดับถัดไป

## กลุ่มผู้อ่าน

- เจ้าของร้านและผู้จัดการสาขา
- พนักงานหน้าร้าน
- ช่างซ่อม
- ผู้รับผิดชอบการส่งมอบ
- ผู้ดูแลระบบและทีมพัฒนา

## หลักการของเอกสารชุดนี้

- อธิบายจากกระบวนการทำงานจริงของร้าน
- ยึดระบบและ Business Rule ที่ตรวจสอบได้จาก Repository
- แยกสิ่งที่ระบบรองรับแล้วออกจากแนวทางในอนาคต
- ไม่อ้างว่าหน้าจอหรือ Runtime ผ่าน หากยังไม่มีหลักฐานการใช้งานจริง
- ปรับปรุงเอกสารควบคู่กับการเปลี่ยนแปลงของระบบ
